# Experiment 4 screening

Added a genuine frame from 0.5 seconds earlier to both specialists, retaining the same twenty-response verification mechanism. The simulator retains that real history independently of its latest-frame buffer.

The 560-token probe produced 44/52 correct specialist decisions. Temporal input recognized the difficult release in episode 58, but regressed on normal transport: the drop specialist interpreted held-adapter movement as falling. Several other close-release cases remained missed.

This variant was not selected for a full live evaluation. Experiment 5 returns to experiment 3's current-only inputs and tests a tighter native success crop, leaving the drop specialist unchanged. The measured probe and runnable code are preserved here.
